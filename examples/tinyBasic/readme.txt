Example running Gordon Brandly's Tiny BASIC for the 68000 on the Motorola
MC68000 Educational Computer Board.

Tiny BASIC was published on the February 1985 issue of Dr. Dobb's Journal.
The binary tinybasic.bin is the TBI68K.HEX of the original distribution,
converted from S-records to a flat image loading at $900. Sources at
https://github.com/jefftranter/68000/tree/master/drdobbs/tinybasic

  Copyright (C) 1984 by Gordon Brandly. This program may be freely
  distributed for personal use only. All commercial rights are reserved.

Run it with:

  go run .

Some programs to try are on the "original" directory of the sources above,
SIEVE.TXT and STARTREK.TXT among them. Paste them in and RUN.
